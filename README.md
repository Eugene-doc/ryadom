# Рядом 0.3.1

Личный мини-чат для Windows и Android. Обменивайтесь текстом, фото, видео и файлами между своими устройствами в одной домашней сети — без интернета и аккаунтов.

**[Скачать для Windows](https://github.com/Eugene-doc/ryadom/releases/download/v0.3.1/Ryadom-Windows.exe) · [Скачать для Android](https://github.com/Eugene-doc/ryadom/releases/download/v0.3.1/Ryadom-Android.apk) · [Все файлы выпуска](https://github.com/Eugene-doc/ryadom/releases/tag/v0.3.1)**

**[Что нового в 0.3.1](docs/releases/0.3.1.md)** — исправлено подключение к самому себе, добавлена проверка сертификата при первом входе и порядок в списке устройств.

## Возможности

- **Текст и медиа** — сообщения, фото, видео и файлы до 512 МБ без сжатия.
- **Wi-Fi и кабель** — устройства общаются в одной локальной подсети роутера.
- **Любое главное устройство** — создайте чат на Windows-ПК или Android-телефоне; выбор можно изменить.
- **Подключение по коду** — поиск устройств в сети или ввод адреса вручную.
- **Работа с Happ** — прямое соединение через домашнюю сеть; при блокировке со стороны VPN понадобится исключение для Рядом.
- **Брандмауэр** — приложение проверяет входящие подключения и подсказывает, что разрешить, если их блокирует брандмауэр Windows или сторонний (ESET, Kaspersky).
- **Защищённый канал** — соединение между приложениями шифруется TLS; отпечаток главного закрепляется при первом подключении после явного подтверждения. Браузерный доступ с других устройств отключён.
- **Управление историей** — удаление отдельных сообщений, очистка чата с файлами и временными передачами, предпросмотр и журнал операций.
- **Своё окно Windows** — WebView2 вместо Edge, правильная иконка, ярлык и панель задач, папка загрузок.
- **Загрузки и версия** — кнопка открытия сохранённых файлов и показ версии при запуске.
- **Проверка подключения** — собственный адрес исключается из поиска, а перед первым доверием показывается отпечаток сертификата главного.

## Быстрый запуск

1. Запустите приложение и выберите **«Создать чат на этом компьютере / телефоне»**.
2. Откройте **«Подключить устройство»**, чтобы увидеть адрес и код.
3. На другом устройстве найдите чат или введите адрес, затем подключитесь по коду.

Главное устройство должно оставаться включённым. История хранится на нём и автоматически не переносится при смене главного. Поддерживаются Windows 10/11 x64 и Android 8.0+.
