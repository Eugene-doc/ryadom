# Дорожная карта

Текущее состояние: **0.3.2 выпущен 19.11.2026** (тег [`v0.3.2`](https://github.com/Eugene-doc/ryadom/releases/tag/v0.3.2)). Раздел безопасности закрыт; Android Happ/VPN — 0.2.2; функции 0.3.0; подключение и доверие — 0.3.1; входящие Windows — 0.3.2.

Обновлено 20.11.2026: добавлены четыре задачи первого приоритета — быстрая очистка всей истории, одна кнопка загрузок, единая идентичность устройств/общий эфемерный чат и восстановление окна из трея. Все выполненные задачи перенесены в конец файла.

> Детали нефиксированных уязвимостей до выпуска исправлений не публикуются. Отчёты «что изменилось в безопасности» для 0.2.0, 0.2.1, 0.3.0, 0.3.1 и 0.3.2 опубликованы в [CHANGELOG.md](../CHANGELOG.md).

## Как пользоваться

- Активные задачи находятся в разделах 0–1; все выполненные задачи собраны в разделе «Выполнено» в конце файла и не смешиваются с текущей работой.
- Приоритет — риск и надёжность, а не объём. Задачи P0 берутся раньше остальных.
- Релиз не выпускается, пока не закрыты его пункты и инженерные ворота; незакрытые ворота фиксируются явно.
- Оценки: S — до 1 дня, M — 2–5 дней, L — 1–2 недели, XL — больше (один разработчик).
- Смена протокола сопровождается версией протокола и сообщением об обновлении клиента.
- Каждый выпуск обязан иметь `docs/releases/<версия>.md` с «что нового»; без него релиз не выпускается.

## 0. Первый приоритет — новые задачи (20.11.2026)

### 0.1 Очистка всей истории одной кнопкой

- [ ] **Кнопка «Очистить всю историю» на виду.** Не прятать функцию в глубине настроек: заметная кнопка в шапке/меню чата. Одно подтверждение с предупреждением, что удаляются все сообщения, вложения и временные `.part` на всех устройствах. После подтверждения — очистка без промежуточного экрана предпросмотра. **S**
- [ ] **Единый результат для всех.** Очистка обновляет состояние всех подключённых устройств, отменяет активные передачи, освобождает место и не оставляет старых файлов. **M**
- [ ] **Согласовать с автоматической очисткой при выходе главного** (задача 0.3): одна операция очистки, один журнал, без двойного удаления и гонок. **M**

### 0.2 Одна кнопка «Открыть загрузки»

- [ ] **Убрать дублирующую кнопку в левом верхнем углу.**
- [ ] **Оставить одну интерактивную кнопку в правом верхнем углу после кнопки поиска.** Порядок в шапке: поиск → загрузки. Сохранить tooltip, `aria-label`, горячую доступность; проверить Windows и Android. **S**

### 0.3 Единая идентичность устройств и общий эфемерный чат

- [ ] **Запомнить устройство один раз.** Устойчивый идентификатор/ключ устройства сохраняется в настройках и используется при каждом подключении независимо от роли «главный/клиент»; список доверенных устройств не зависит от текущего главного и не размножается при смене ролей. **L**
- [ ] **Автоматически вспоминать устройство при подключении.** После первого подтверждения устройство переподключается по сохранённой идентичности; смена IP, главного или перезапуск не создаёт новую запись и не требует повторного кода без необходимости. **M**
- [ ] **Один общий чат для всех устройств.** Сообщения, вложения и состояние чата одинаковы на всех устройствах независимо от того, кто сейчас главный; нет разных историй у разных главных. **XL**
- [ ] **Эфемерная история без конфликтов версий.** При штатном выключении программы или полном выходе главного устройства из чата история очищается на всех устройствах; настройки, доверенные устройства и сертификаты сохраняются. При аварийном завершении — очистка по маркеру при следующем запуске. Перед очисткой — явное предупреждение. **XL**
- [ ] **Протокол и миграция.** Спроектировать протокол следующей версии: устойчивая идентичность, единая сессия/эпоха чата, очистка без расхождений; продумать переход с 0.3.x и поведение при несовместимых клиентах. **L**
- [ ] **Тесты и угрозы.** Подмена устройства, повторное подключение, смена главного, параллельное выключение и очистка, обрыв сети; тесты на отсутствие старых сообщений после очистки. **L**

### 0.4 Восстановление окна из трея

- [ ] **Повторный запуск не должен показывать «Рядом уже запущен».** Второй процесс передаёт сигнал первому и завершается; первый разворачивает существующее окно чата. **M**
- [ ] **Клик по закреплённой иконке на панели задач, ярлыку или основному значку приложения** восстанавливает свёрнутое в трей/минимизированное окно и выводит его на передний план. **M**
- [ ] **Надёжный single-instance IPC.** Именованный канал/зарегистрированное сообщение/именованный объект; обработать случай, когда окно было закрыто, но процесс жив, и когда первый экземпляр ещё запускается. **M**
- [ ] **Проверить Windows 10/11:** закрепление, ярлык, повторный запуск, окно уже открыто/свёрнуто/скрыто в трей. **S**

### 3.1 0.3.2 — входящие подключения Windows
