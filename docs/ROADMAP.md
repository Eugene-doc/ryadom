# Дорожная карта

Текущее состояние: **0.2.1** (выпуск 15.11.2026; раздел 1 выполнен, исправления по ревью Codex вошли в 0.2.1). Плановые версии: **0.2.x** — надёжность, **0.3.0** — функции. Инженерные работы идут параллельно.

Обновлено 15.11.2026: отмечены выполненные пункты, в раздел 4 добавлены 9 функциональных задач пользователя.

> Детали нефиксированных уязвимостей до выпуска исправлений не публикуются. Для 0.2.0 и 0.2.1 отчёт «что изменилось в безопасности» опубликован в [CHANGELOG.md](../CHANGELOG.md).

## Как пользоваться

- Приоритет — риск и надёжность, а не объём.
- Релиз не выпускается, пока не закрыты его пункты и инженерные ворота раздела 5; для 0.3.0 — раздел 1, критические пункты раздела 2 и раздел 5.
- Оценки: S — до 1 дня, M — 2–5 дней, L — 1–2 недели, XL — больше (один разработчик).
- Смена протокола сопровождается версией протокола и сообщением об обновлении клиента.

## 1. Срочные правки безопасности

Выполнено в 0.2.0; исправления по независимому ревью Codex — в 0.2.1 (см. [CHANGELOG.md](../CHANGELOG.md)). Клиенты и главные 0.1.x несовместимы с 0.2.x; браузерный доступ к главному отключён (TLS с самоподписанным сертификатом не может быть закреплён браузером).

- [x] **Шифрование канала и подлинность главного устройства.** TLS 1.2 между приложениями, проверка отпечатка главного при первом подключении, HttpOnly/SameSite-сессии. **L**
- [x] **Управление сессиями.** Выход действительно отзывает доступ, ограниченный срок жизни сессий, отзыв всех устройств. **M**
- [x] **Безопасное подключение новых устройств.** Одноразовый код, подтверждение на главном, понятное уведомление, журнал подключений. **M**
- [x] **Защита локального служебного API и одноразовые токены.** Секреты не появляются в командной строке; служебные вызовы требуют native-ключ. **S**
- [x] **Устойчивость к медленным и зависшим соединениям.** Таймауты и лимиты соединений, отдельный пул для SSE, ограниченные очереди рассылки. **M**
- [x] **Квоты и контроль места.** Общий лимит хранилища, лимиты на устройство и частоту передач, проверка свободного места. Автоочистки пока нет. **M**
- [x] **Безопасные правила брандмауэра.** Только частная сеть; атомарная настройка с проверкой обоих правил, повторная настройка, достоверная диагностика. **S**

## 2. Средние

Не блокируют 0.2.x, закрываются до 0.3.0.

- [ ] **Постоянная идентичность главного.** Устройства запоминают главный по идентификатору и отпечатку, а не по IP; корректное переподключение при смене адреса. **M**
- [ ] **Управление сессиями и устройствами в интерфейсе.** Список, последняя активность, отзыв всех, журнал. **M**
- [ ] **Защита локального ключа.** Шифрование/ACL, запрет чтения другими пользователями. **S**
- [ ] **Android: история в SQLite.** Транзакции и индексы вместо одного JSON-файла; загрузка истории в фоне при старте сервиса. **L**
- [ ] **Android: сеть и сон.** Восстановление после сна, смены сети/IP и переподключения Wi-Fi; автоперезапуск сервиса. **M**
- [ ] **Windows: сеть и производительность.** Меньше опросов адаптеров, атомарная запись состояния сети, альтернативный порт при занятости. **M**
- [ ] **Логи и диагностика.** Перехват необработанных ошибок, файл-лог и экспорт диагностики без телеметрии. **S**
- [ ] **Целостность серверного бинарника.** Проверка хэша извлечённого сервера перед запуском. **S**
- [x] **Версия протокола и совместимость.** `PROTOCOL=2` в health/state, предупреждение о несовместимости на клиенте, разовая миграция legacy-сессий Android; отдельная проверка версии клиента/хоста — при следующем изменении протокола. **M**
- [ ] **Глобальные лимиты.** Ограничения на попытки подключения и на количество служебных соединений. **S**

## 4. Функциональные

0.3.0 и далее, по ценности для пользователя. Задачи ниже добавлены по запросу пользователя 15.11.2026 и в 0.2.x ещё не реализованы.

- [ ] **Удаление отдельных сообщений.** Автор удаляет своё сообщение, главный — любое; подтверждение, обновление у всех подключённых, удаление связанного файла. **M**
- [ ] **Очистка чата с удалением файлов.** Полная очистка истории и вложений, включая временные `.part`/кэш; подтверждение, показ освобождённого места; не затрагивать другие чаты. **M**
- [ ] **Частные чаты и общий чат.** Разделить переписку на личные диалоги (каждый видит только свои) и общий чат; права главного, непрочитанные, присутствие. **XL**
- [ ] **Общий чат с явным согласием.** Создаётся вручную: выбор участников, приглашение, принятие/отклонение, список участников и выход; без автоматического добавления всех устройств. **L**
- [ ] **iOS-версия.** Нативное приложение (Swift/SwiftUI) с тем же протоколом TLS и спаривания; iPhone/iPad как клиент. macOS/Linux — после iOS. **XL**
- [ ] **Кнопка «Открыть папку загрузок».** В интерфейсе чата — открыть папку сохранённых вложений (Проводник Windows / Downloads или папка приложения на Android), подсветить последний файл. **S**
- [ ] **Закрепление на панели задач Windows.** Явная команда/ярлык для закрепления Рядом на taskbar и в меню «Пуск», без зависимости от браузера. **S**
- [ ] **Иконка при закреплении.** Исправить отображение иконки Edge вместо Рядом: собственная иконка EXE/ярлыка, AppUserModelID, пересоздание ярлыка; проверить Windows 10/11. **S**
- [ ] **Показ версии при запуске.** При старте программы показывать текущую версию (Windows и Android), чтобы пользователь сразу видел, что установлено. **S**
- [ ] Уведомления о новых сообщениях и счётчик непрочитанных. **L**
- [ ] Шифрованный экспорт/импорт истории и файлов, перенос на нового главного. **L**
- [ ] QR-подключение с адресом, кодом и отпечатком; мастер настройки. **M**
- [ ] Надёжные большие передачи: докачка, контрольные суммы, отмена; миниатюры и сжатие; HEIC/AVIF. **L**
- [ ] Блокировка приложения PIN/биометрия, скрытие превью. **M**
- [ ] Полнотекстовый поиск по всей истории на главном. **M**
- [ ] Тёмная тема, английская локализация, доступность. **M**
- [ ] Автозапуск, автоперезапуск, «Проверить обновления». **M**
- [ ] Проверка вложений и предупреждения об опасных типах. **M**
- [ ] Локальное резервное копирование по расписанию. **M**
- [ ] Голосовые сообщения (опционально). **XL**
