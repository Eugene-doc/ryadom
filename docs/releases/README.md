# Примечания к выпускам

Здесь хранится «что нового» для каждого выпуска Рядом. Эти файлы — часть релиза, а не временный текст для GitHub.

## Правило

Каждый выпуск обязан иметь файл `docs/releases/<версия>.md` **до** сборки и публикации. Без него релиз не выпускается.

В файле должны быть:

1. Версия, дата, тег и ссылка на GitHub Release.
2. Главное: что изменилось для пользователя.
3. Совместимость и порядок обновления (протокол, Android/Windows, WebView2).
4. Что проверено автоматически и вручную.
5. Ограничения и известные риски.
6. Список файлов выпуска и ссылки на них.

Тот же текст используется в описании GitHub Release. После выпуска файл не переписывается задним числом; исправления оформляются отдельным выпуском.

## Чек-лист выпуска

- [ ] Создан `docs/releases/<версия>.md` по [`_template.md`](_template.md).
- [ ] Обновлены `README.md`, `CHANGELOG.md`, `docs/ROADMAP.md` и `START-HERE.txt`.
- [ ] Версия синхронизирована в `package.json`, `server.cjs`, Windows, Android и UI; `tests/version.test.cjs` зелёный.
- [ ] Собраны EXE/APK/source zip, проверены хэши, подписаны EXE и `SHA256SUMS.txt`.
- [ ] GitHub Release использует текст из `docs/releases/<версия>.md` и содержит все артефакты.
- [ ] Ссылка на примечания добавлена в README и CHANGELOG.
