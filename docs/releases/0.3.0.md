# Рядом 0.3.0 — что нового

**Дата:** 16.11.2026  
**Статус:** выпущен  
**Тег:** [`v0.3.0`](https://github.com/Eugene-doc/ryadom/releases/tag/v0.3.0)  
**Коммит:** `e5f2da5`  
**GitHub Release:** <https://github.com/Eugene-doc/ryadom/releases/tag/v0.3.0>

## Главное

0.3.0 — функциональное обновление: управление историей, загрузки, показ версии и собственное окно Windows на WebView2. Протокол 3; Android `versionCode 8`, Windows `0.3.0.0`.

- **Удаление сообщений.** Автор удаляет своё сообщение, главный — любое. Вместе с сообщением удаляется вложение; у всех подключённых устройств оно исчезает. Удалённое сообщение нельзя «воскресить» повторной отправкой с тем же `requestId`.
- **Очистка чата с файлами.** Предпросмотр количества сообщений, файлов и байтов; подтверждение; отмена активных передач; удаление `.part`; освобождение квоты. Если файл не удалось стереть физически, операция получает `partial` и повторяется при следующем запуске.
- **Загрузки.** В Windows-окне кнопка «Открыть загрузки» открывает `%USERPROFILE%\Downloads\Рядом` и выделяет последний файл. WebView2 сохраняет туда скачивания. На Android кнопка показывает сохранённые через Рядом файлы.
- **Собственное окно Windows.** WinForms + WebView2 вместо окна Edge: иконка Рядом, AppUserModelID `Ryadom.Chat`, меню создания ярлыка и инструкция по закреплению. SDK фиксированной версии встроен в EXE, `WebView2Loader.dll` извлекается в `%LOCALAPPDATA%\Ryadom\webview2`.
- **Версия и протокол 3.** Версия видна при запуске, в Windows-панели и настройках. Схема данных мигрирует без потери истории; `chat.id=legacy`, ревизии, epoch, tombstones и операции очистки.
- **Надёжность после ревью.** Исправлены гонки очистки и загрузок, восстановление незавершённого удаления, коллизии имён загрузок, устаревшие ответы интерфейса и порядок SSE; WebView2 получил асинхронный fallback.

## Совместимость и обновление

- **Протокол 3.** Обновите все устройства: клиенты 0.2.x и старее несовместимы с главным 0.3.0.
- **Windows 10/11 x64.** Для собственного окна нужен **Microsoft Edge WebView2 Runtime** (в Windows 11 обычно установлен). Без него приложение предупредит и временно откроет Edge-вариант. SDK встроен в EXE, отдельно ставить его не нужно.
- **Android 8.0+.** `versionCode 8`; APK ставится поверх 0.2.x с сохранением данных. Не удаляйте приложение перед обновлением.
- Перед обновлением Windows выключите старый Рядом через значок рядом с часами. История и ключи остаются в `%LOCALAPPDATA%\Ryadom`; для резервной копии скопируйте эту папку при выключенном приложении.

## Проверено

- Node 39/39: сервер, безопасность, прокси, функциональные сценарии удаления/очистки, версия, UI/Windows-контракты.
- Android JVM + Java-host: 18 проверок адресов, удаление/права/очистка/epoch, TLS/TOFU, SSE, абсолютные таймауты и квоты, FunctionalTest и рестарт с восстановлением — `fail 0`.
- Windows transport/TLS/firewall: physical-interface + TCP, LAN discovery, TLS/TOFU, deadline, смена сертификата и парсер правил — PASS.
- WebView2: отдельный harness открывает окно «Рядом» и запускает `msedgewebview2`.
- Релиз: digest’ы всех ассетов совпадают с `SHA256SUMS.txt`; подпись OpenSSH проверена. APK: `versionCode 8`, `versionName 0.3.0`; EXE: `0.3.0.0`. Authenticode-сертификат самоподписанный, SmartScreen ему не доверяет.

## Ревью Codex

Три делегации: планирование, code review и повторная проверка исправлений. Первый аудит дал 5 High / 8 Medium / 3 Low, повторный — ещё 3 High / 2 Medium. Все High/Medium исправлены. Финальный внешний проход после `e5f2da5` не запускался: бюджет 3/3 исчерпан; исправления подтверждены тестами и чтением кода. Журнал — `delegations/journal.md`.

## Ограничения

- Реальный Android, живая связка Windows↔Android и полная матрица Windows 10/11 **не проверялись**.
- SAF после перезапуска, закрепление и повторный запуск окна проверяются пользователем.
- iOS и частные/общие чаты в 0.3.0 не входят; они запланированы на отдельные выпуски.
- Передача между приложениями — TLS 1.2 без сквозного шифрования.
