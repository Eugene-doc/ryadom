# Рядом 0.3.1 — что нового

**Дата:** 16.11.2026  
**Статус:** выпущен  
**Тег:** [`v0.3.1`](https://github.com/Eugene-doc/ryadom/releases/tag/v0.3.1)  
**GitHub Release:** <https://github.com/Eugene-doc/ryadom/releases/tag/v0.3.1>

## Главное

0.3.1 — срочный патч подключения, безопасности первого входа и порядка в списке устройств. Протокол остаётся **3**; обновите обе платформы.

- **Нельзя подключиться к самому себе.** Windows и Android больше не показывают собственный главный узел в поиске и отклоняют его адрес с понятным сообщением. Это исправляет случай, когда устройство «не видит» главное, хотя другие к нему подключаются: оно пыталось соединиться со своим же адресом.
- **Проверка сертификата при первом входе.** При первом подключении показывается SHA-256 отпечаток сертификата главного и запрос на доверие; отпечаток можно сверить в настройках главного. Раньше первый отпечаток закреплялся молча.
- **Сброс устаревшего доверия.** Если сертификат главного изменился, Windows и Android предлагают сбросить доверие только для этого адреса, а не удалять общий файл вручную.
- **Меньше путаницы с прошлыми подключениями.** В списке устройств показывается последняя активность, устройства сортируются по сети/активности; при переходе в роль главного старый адрес клиента больше не подставляется автоматически. На главном появилась кнопка «Забыть неактивные устройства».
- **История и главное.** В настройках явно сказано: история хранится на текущем главном, при его смене открывается история нового главного, автоматического переноса нет.

## Совместимость и обновление

- **Протокол 3**, как в 0.3.0. Windows и Android 0.3.0 совместимы по протоколу, но патч нужно поставить на все устройства.
- **Windows 0.3.1.0.** Требуется Microsoft Edge WebView2 Runtime для собственного окна; без него — запасной Edge.
- **Android 0.3.1, `versionCode 9`.** Устанавливается поверх 0.3.0 с сохранением данных.
- Если сертификат главного менялся, после обновления подтвердите новый отпечаток. Старые доверия можно сбросить в диалоге «Сертификат главного изменился».

## Проверка соединения

1. Убедитесь, что на главном устройстве запущен Рядом и оно подключено к домашней сети.
2. На другом устройстве нажмите «Найти в сети» и выберите **другое** устройство, а не свой адрес.
3. Сверьте отпечаток сертификата с главным: Настройки → Безопасность.
4. Если показывается «Нет ответа», проверьте входящие TCP 4280 / UDP 42800 и сторонний брандмауэр на главном; Happ может оставаться включённым.

## Проверено

- Node 39/39: сервер, безопасность, прокси, функциональные сценарии, версия, UI/Windows-контракты.
- Android JVM + Java-host: адреса, удаление/очистка, TLS/TOFU, SSE, таймауты, квоты, FunctionalTest — `fail 0`.
- Windows transport/TLS/firewall: self-address detection, pin confirmation helpers, TLS/TOFU, deadline, смена сертификата, firewall — PASS.
- WebView2 harness: окно и `msedgewebview2` запускаются.

## Ограничения

- Реальный Android, живая связка Windows↔Android и полная матрица Windows 10/11 не проверялись.
- Автоматическая проверка self-discovery ограничена выбранным сетевым интерфейсом; при нестандартной конфигурации VPN/нескольких адаптеров адрес всё равно отклоняется перед подключением.
- История по-прежнему не синхронизируется между разными главными; перенос запланирован отдельно.
