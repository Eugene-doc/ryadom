# Рядом 0.4.1 — версия в имени файла

**Дата:** 21.11.2026  
**Статус:** выпущен  
**Тег:** `v0.4.1`  
**GitHub Release:** https://github.com/Eugene-doc/ryadom/releases/tag/v0.4.1

## Главное

- Имена готовых файлов теперь содержат версию: **`Ryadom-Windows-0.4.1.exe`** и **`Ryadom-Android-0.4.1.apk`**. Скачанный файл больше не выглядит одинаково для всех выпусков.
- То же правило применяется к будущим сборкам автоматически: версия берётся из `package.json`.
- Содержимое и протокол не менялись: это исправление только имён артефактов и документов.

## Совместимость

- Протокол: **4** (без изменений).
- Windows: **0.4.1.0**.
- Android: **0.4.1**, `versionCode 13`.
- Обновление поверх 0.4.0 сохраняет настройки и identity; история текущей сессии по-прежнему эфемерна и очищается при завершении главного.

## Проверено

- Node: **42/42**.
- Android JVM + Java-host: **40/40**.
- Windows: transport/TLS/discovery/firewall — PASS.
- Версии синхронизированы; сборка выдаёт имена с версией.
- Codex в этом фиксе не привлекался: изменение затрагивает только имена артефактов и документацию.

## Ограничения

- Ограничения 0.4.0 сохраняются: identity — TLS-защищённый bearer-токен, roster/discovery не подписаны, автоматического handoff нет. Подробности — в [0.4.0.md](0.4.0.md).
