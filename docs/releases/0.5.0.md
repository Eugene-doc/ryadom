# Рядом 0.5.0 — частные E2E-чаты

**22 ноября 2026** · протокол 4 · Android `versionCode 15` · Windows `0.5.0.0`

## Что нового

- **Личные диалоги.** В сайдбаре появился список частных чатов; диалог создаётся с выбранным устройством.
- **E2E-шифрование.** Каждое устройство генерирует ECDH P-256 ключ на текущую сессию. Из общего секрета выводится AES-256-GCM ключ; сервер хранит только ciphertext и метаданные.
- **Safety number.** Отпечаток пары ключей можно сверить вне чата и подтвердить. Без сверки действует TOFU-предупреждение.
- **Зашифрованные файлы.** Вложения шифруются на устройстве; имя, MIME и размер передаются в зашифрованном metadata-envelope, сервер хранит только ciphertext.
- **Непрочитанные.** Бейджи и отметка прочтения при открытии диалога.
- **Права доступа.** Сообщения и файлы личного диалога доступны только его участникам; постороннее устройство получает `403`.
- **Эфемерность.** При завершении сессии главного удаляются личные чаты, участники, ключи, сообщения и файлы.
- **Android-хост.** Частные чаты, ключи, unread и зашифрованные вложения работают и на Android-главном.

## Ограничения

- Личный диалог создаётся сразу с выбранным устройством; отдельного приглашения/принятия в 0.5 нет.
- История и ключи живут только до завершения сессии главного.
- Хост видит метаданные (участники, время, размер), но не plaintext. При подмене публичных ключей защита зависит от сверки safety number.
- Группы, экспорт/импорт, QR и большие передачи — 0.6–0.9.
- iOS не входит в 0.5.

## Проверки

- Node **43/43**.
- Android **41/41**.
- Windows/Android сборки с `e2ee.js`.
- Проверены ECDH/AES-GCM для текста и файлов, safety number, доступ только участникам, unread/read.

## Обновление

Обновите **все** устройства: старые клиенты несовместимы с главным 0.5.0 (протокол 4).
