# Рядом 0.4.2 — окно из трея и один экземпляр

**Дата:** 21.11.2026  
**Статус:** выпущен  
**Тег:** `v0.4.2`  
**GitHub Release:** https://github.com/Eugene-doc/ryadom/releases/tag/v0.4.2

## Главное

- Повторный запуск Рядом (ярлык, закреплённая иконка, основной значок) больше **не показывает «Рядом уже запущен»**. Второй процесс передаёт первому запрос на активацию и завершается.
- Первый экземпляр показывает окно чата из трея, восстанавливает минимизированное окно и выводит его на передний план.
- Если окно было закрыто крестиком (осталось в трее), показывается тот же экземпляр окна без перезагрузки WebView.
- Если активация пришла во время выбора роли или запуска хоста, запрос запоминается и окно открывается после готовности; второй хост не запускается.

## Как это работает

- Единственный экземпляр по-прежнему защищён mutex `Local\Ryadom.PersonalChat`.
- Для активации используется именованный pipe с правами текущего пользователя и сессии.
- Второй процесс передаёт первому `AllowSetForegroundWindow`, чтобы окно могло выйти вперёд.
- Если первый процесс аварийно завершился и mutex остался abandoned, следующий экземпляр может стать основным.
- UI-запросы маршалятся на STA-поток через `BeginInvoke`; окно и роль не затрагиваются из фонового потока.

- Node: **42/42**.
- Android JVM + Java-host: **40/40**.

## Ограничения

- Полная ручная матрица Windows 10/11 (видимое/минимизированное/скрытое окно, закрепление, elevated/normal) не пройдена на двух системах.
- `SetForegroundWindow` подчиняется политике Windows; при фоновом программном запуске возможен только flash панели задач.
- Ограничения identity/roster из 0.4.0 сохраняются.
